# Homelab SysAdmin: Linux, Red Hat e OpenShift

Infrastruttura di laboratorio su Proxmox che riproduce il lavoro quotidiano di un sistemista: server RHEL 9 amministrati e automatizzati con Ansible, cluster Kubernetes (k3s) e OpenShift, monitoraggio con Grafana, Kibana e Datadog, gestione di incident e change su ServiceNow.
Tutte le VM sono create con Terraform e configurate con Ansible: l'ambiente si ricostruisce da zero partendo da questo repository.
